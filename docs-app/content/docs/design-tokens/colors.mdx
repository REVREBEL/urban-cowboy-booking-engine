Every swatch below is painted by its own custom property. The token name, its declaration and the
resolved CSS value are shown next to it, and each can be copied. Primitive shades come from
`colors.css`; semantic roles and control colors come from `index.css` and `utilities.css`.

<ColorsShowcase />

## Reading the palette

Primitive families present all declared numeric shades plus the family aliases such as `--paper`
and `--lake-forest-muted`. Semantic roles are shown with sample text on their own background token,
where a matching `*-foreground` token exists. Contrast pairings use the pairs already defined by
the theme rather than newly chosen color combinations.

The control section uses the real shared `Button` with documented props. Hover, focus and active
colors come from the same `control-color-*` utilities; the loading and disabled examples use the
component's own states.

## Responsive notes

Swatch grids collapse from six columns to two on narrow screens. The semantic cards and pairing
samples wrap to one column, so no horizontal scrolling is needed to read a token name or value.
