Each card is painted by its own live custom property and shows the token name, its HEX and OKLCH values; the card's copy button copies the HEX value. The colors and card layout follow the main-colors frame in the Figma design system.

<ColorsShowcase />

## Reading the palette

The twelve cards show the main brand colors in design order. Values are read from the booking-engine theme, so a card's displayed HEX and OKLCH always match the color currently rendered by its token.

## Responsive notes

The cards sit in two columns on wide screens and collapse to one column on narrow screens, so no horizontal scrolling is needed to read a token name or value.
