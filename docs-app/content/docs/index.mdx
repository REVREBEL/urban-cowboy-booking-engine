the same implementations used by the booking application; no Mews, Worker, D1 or payment code
runs in this site.

## Coverage

Each reference page is listed in `components/meta.json` and imports the real component through a
client story control. The docs build and Playwright smoke checks verify the published pages,
interactive controls, assets and responsive layouts.
