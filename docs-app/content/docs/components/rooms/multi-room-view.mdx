The multi-room view components present a building's room offerings in various editorial layouts. Demos use deterministic room card data fixtures; selection actions are recorded locally.

## Building Header — MultiRoomViewBuilding

The building header shows the building name, tagline, description and optional icon. Four layout variants control the arrangement of content and icon.

### Stacked Left

## Room List — MultiRoomViewList

Displays up to three building groups as vertical stacks. Each group is a `MultiRoomViewListItem` with an optional building section slot. The component is exported from `RoomTypeList.tsx`.

<MultiRoomViewListStoryControl />

### Usage

```tsx
import { MultiRoomViewList, MultiRoomViewListItem, MultiRoomViewBuilding } from '@/components/rooms';

const buildingGroup1 = (
  <MultiRoomViewListItem
    layout="Row"
    roomTypes={alpineRoomTypes}
    buildingSectionSlot={
      <MultiRoomViewBuilding
        buildingName="Alpine"
        buildingDescription="Built into the hillside..."
        buildingTagline="This is Where you Come to Soak..."
        layout="StackedCenter"
      />
    }
  />
);

<MultiRoomViewList buildingGroup1={buildingGroup1} buildingGroup2={buildingGroup2} />
```

## Responsive behaviour

- Building header layouts adapt: Row/Row Reverse stack on mobile; Stacked variants remain stacked
- Room list uses single-column stack on all viewports
- Room type cards maintain aspect ratio and stack on narrow screens

## Usage

```tsx
import { MultiRoomViewBuilding, MultiRoomViewList, MultiRoomViewListItem, MultiRoomViewRoomTypeCard } from '@/components/rooms';

// Building header
<MultiRoomViewBuilding
  buildingName="Alpine"
  buildingDescription="Built into the hillside..."
  buildingTagline="This is Where you Come to Soak..."
  layout="Row"
  displayBuildingIcon={true}
  buildingIconSlot={<BuildingIcon buildingName="Alpine" />}
/>

// Room list (slot-based)
const buildingGroup1 = (
  <MultiRoomViewListItem
    layout="Row"
    roomTypes={[
      { id: "1", buildingName: "Alpine", numberOfBeds: "8 beds", price: "$596", roomTypeName: "Alpine Bathing Suite", state: "Focus" },
      { id: "2", buildingName: "Alpine", numberOfBeds: "6 beds", price: "$445", roomTypeName: "Alpine King Suite", state: "Default" },
    ]}
    buildingSectionSlot={
      <MultiRoomViewBuilding
        buildingName="Alpine"
        buildingDescription="Built into the hillside..."
        buildingTagline="This is Where you Come to Soak..."
        layout="StackedCenter"
      />
    }
  />
);

<MultiRoomViewList buildingGroup1={buildingGroup1} />

// Standalone room type card
<MultiRoomViewRoomTypeCard
  buildingName="Alpine"
  numberOfBeds="8 beds"
  price="$596"
  roomTypeName="Alpine Bathing Suite with Den"
  state="Focus"
/>
```
