`RoomsListCard` presents a shaped room in the results list. The demo uses a deterministic
`ShapedRoom` fixture with no rates; selection actions are recorded locally and never create a
reservation.

<RoomsListCardStoryControl />

## Themes

<RoomsListCardCopperStoryControl />

| Prop | Values | Notes |
| --- | --- | --- |
| `room` | `ShapedRoom` | Canonical Mews-shaped room data from the D1/Webflow catalog |
| `theme` / `color` | `paper`, `copper`, `lake-forest` | Presentation token |
| `layout` | `left`, `right` | Media/body arrangement |
| `isTopMatch` | boolean | Match badge presentation |
| `onSelectRoom`, `onOpenRoomDetails` | callbacks | Docs harness records the action only |
| `imageBaseUrl` | string | Base path for room imagery |

## Responsive behaviour

The media and body columns stack on narrow screens. The card keeps a full-width action target and
does not introduce horizontal scrolling.
