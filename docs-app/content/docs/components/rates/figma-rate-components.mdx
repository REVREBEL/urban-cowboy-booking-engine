These components implement the production rate card designs from Figma (1390:31339). They are responsive without fixed dimensions and use shared design-system button controls. Prices and policies in demos are static fixtures; callbacks record actions locally and never call Mews or start payment.

### Props

| Prop | Values | Notes |
| --- | --- | --- |
| `eyebrow` | string | Upper label (e.g., "Keep Your Options Open") |

| `total` | number | Total price |

| `perks` | string[] | Package perks (package variant only) |
| `confirmLabel` | string | CTA button text |
| `onDetails` | `() => void` | Details click callback |
| `onConfirm` | `() => void` | Confirm booking callback |

## Responsive behaviour

- Rate card: constrained max-width (~523px), scrolls inside bounded container on narrow screens
- Detail popup: full-width on mobile, max-width on desktop
- Policy timeline: stacks vertically on narrow screens
- Buttons use shared design-system controls with proper touch targets

## Usage

```tsx
import { FigmaRateCard, FigmaRateDetailPopup, FigmaPolicyTimeline } from '@/components/rates/FigmaRateComponents';
import { buildCancellationTimeline } from '@/lib/cancellationTimeline';

const timeline = buildCancellationTimeline("2026-11-20", "2027-01-13", 285.60, {
  freeCancelDays: 14,
  balanceDueDays: 5,
  depositShare: 0.5,
});

// Rate card
<FigmaRateCard
  eyebrow="Keep Your Options Open"
  name="Ride Easy"
  description="Our standard rate for guests who want a little more freedom around their plans."
  policy="Free Cancellation Until December 31"
  roomSummary="Alpine Bathing Suite, 1 night for 2 Adults"
  total={285.60}
  currency="USD"
  variant="default"
  onDetails={handleDetails}
  onConfirm={handleConfirm}
/>

// Detail popup
<FigmaRateDetailPopup
  name="Ride Easy"
  eyebrow="Keep Your Options Open"
  description="Our standard rate..."
  nightly={285.6}
  currency="USD"
  nights={1}
  subtotal={255}
  taxes={30.6}
  total={285.6}
  dueToday={142.8}
  policyText="Cancellation: Free Cancellation until Dec 30, 2026"
  timeline={timeline}
  arrivalDate="2027-01-13"
  onClose={handleClose}
  onConfirm={handleConfirm}
/>

// Policy timeline
<FigmaPolicyTimeline
  timeline={timeline}
  arrivalDate="2027-01-13"
  total={285.60}
  currency="USD"
/>
```
