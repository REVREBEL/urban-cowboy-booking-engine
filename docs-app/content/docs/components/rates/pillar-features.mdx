`PillarFeatures` displays a horizontal row of feature highlights, each with an icon, label and description. Used for merchandising key amenities in rate presentations. The demo uses static feature data.

<PillarFeaturesStoryControl />

## Props

`PillarFeatures` takes no props - it renders a static set of three pillars.

## Responsive behaviour

- Three columns on desktop
- Stacked on mobile
- Icons and text scale proportionally

## Usage

```tsx
import { PillarFeatures } from '@/components/rates/PillarFeatures';

<PillarFeatures />
```
