`Arrive` is the first step of the photo journey. It presents editorial intent cards and a
date/party selector, then hands the caller a `Match` or `Browse` action. The docs harness owns
all state locally; `loadCalendar` is a no-op, so no Mews availability or pricing request is
made.

## Responsive behaviour

The editorial cards and search controls wrap on narrow screens; the calendar panel opens in
place rather than as a modal. The demo keeps the full-screen layout of the real journey step.

## Usage

```tsx
import { Arrive } from '@/journey/PhotoArrival';

<Arrive {...journeyState} stories={editorialStories} onMatch={startMatch} onBrowse={browseAll} />
```
