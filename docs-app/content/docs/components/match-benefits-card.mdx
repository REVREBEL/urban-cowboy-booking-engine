} from '~/components/story-controls';

`MatchBenefitsCard` is the explanation surface for a recommended room: it pairs the room summary
with ordered reasons and optional save/choose actions. The badge and pointing-hand assets are
root-relative, so the docs instance passes `imageBaseUrl` to resolve them under the Pages base
path. No reservation is created by the demo.

<MatchBenefitsCardStoryControl />

## Variants

The compact variant hides actions and adds custom headings and intro copy.

<MatchBenefitsVariantsStoryControl />

## Responsive behaviour

The card uses a narrow reading column on phones and two columns at `lg` in the comparison grid.
Feature chips wrap instead of scrolling horizontally.

## Usage

```tsx
import { MatchBenefitsCard } from '@/components/booking/results/MatchBenefitsCard';

<MatchBenefitsCard room={match} reasons={reasons} imageBaseUrl={basePath} />
```
