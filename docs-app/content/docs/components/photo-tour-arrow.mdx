import { PhotoTourArrowStoryControl, PhotoTourArrowVariantsStoryControl } from '~/components/story-controls';

`PhotoTourArrow` renders a small arrow image rotated for the four cardinal directions. It
switches to an inline SVG chevron when `chevron` is set or when the asset fails to load, so a
missing icon never leaves a blank control. Both modes are decorative and hidden from assistive
technology; the surrounding button supplies the accessible action.

<PhotoTourArrowStoryControl />

## Migrated states

The former `Arrow`, `Chevron`, `Back`, `Playground`, `ChevronDirections`,
`AssetVsChevronComparison` and `Sizes` stories are represented in the grid below.

<PhotoTourArrowVariantsStoryControl />

## Responsive behaviour

The arrow has no layout of its own beyond the requested pixel size. The comparison grid wraps
from a single column on phones to multiple columns at `sm`, so all directions and sizes remain
visible without horizontal scrolling.

## Usage

```tsx
import { PhotoTourArrow } from '@/journey/PhotoTourArrow';

<PhotoTourArrow direction="right" size={24} />
```
