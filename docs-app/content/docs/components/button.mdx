`Button` owns every part of its presentation. Callers control placement and the documented
props only; do not override radius, padding, colour, hover, focus or pressed behaviour with
local classes.

## Interactive playground

<ButtonStoryControl />

## Variants, sizes and states

The grid below covers palette colours, text cases, border colours, sizes and interactive states.
Palette colours render on the light docs surface. The `light` and `paper` schemes use paper as
their outline and transparent text colour, so those two controls sit in a small dark specimen to
keep their labels readable; the rest of the grid stays on the light page.

<ButtonVariantsStoryControl />

## Responsive behaviour

Buttons keep their intrinsic width and wrap within a flex container. On narrow screens the
variant grid stacks by row; no nested horizontal scrolling is introduced by the docs frame.

## Usage

```tsx
import { Button } from '@/components/ui/Button';

<Button variant="filled" colorScheme="lake-forest" onClick={continueBooking}>
  Book Your Stay
</Button>
```
