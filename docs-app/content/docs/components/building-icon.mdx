`BuildingIcon` renders one of ten building silhouettes as a CSS mask filled with a theme
colour. It is decorative: the outer element carries a `role="img"` and an accessible label,
while the coloured mask itself is hidden from assistive technology. The component is used
across room cards and lodging-family merchandising to give each place a recognisable shape.

## Props

| Prop | Values | Notes |
| --- | --- | --- |
| `buildingName` | `Default`, `Alpine`, `SlideMountain`, `Ralphs`, `Chalet`, `ForestHaus`, `MountianViewHaus`, `EstonianSauna`, `Cabin`, `OpasCabin` | Selects the silhouette and its accessible label |
| `color` | `Smoke`, `Snow`, `LakeForest`, `Ash`, `Alpine` | Fill colour applied through the mask |
| `className` | string | Placement only; height is set per silhouette |
| `imageBaseUrl` | string | Optional asset URL prefix for sites served under a base path |

## Responsive behaviour

Each silhouette has an intrinsic height that mirrors the Figma geometry; the icon keeps its
aspect ratio and scales with the theme. The variants grid moves from two columns to four at
the `sm` breakpoint, and the colours row wraps on narrow screens.

## Usage

```tsx
import { BuildingIcon } from '@/components/rooms/BuildingIcon';

<BuildingIcon buildingName="Alpine" color="LakeForest" />
```
