`DogToggleButton` is a large pressable card used on the arrival screen. It is controlled:
the caller owns `selected` and responds to `onToggle`. The component owns its own icons,
states and accessible label.

<DogToggleStoryControl />

## Props and states

| Prop | Values | Notes |
| --- | --- | --- |
| `selected` | boolean | Drives the visual treatment and `aria-pressed` |
| `onToggle` | `() => void` | Called on activation; the caller updates `selected` |
| `className` | string | Placement only |

Former Storybook states `Inactive` and `Selected` are represented by the interactive
control. Two icon assets are swapped by breakpoint; both are decorative and hidden from
assistive technology, with a visually hidden label on the button.

## Responsive behaviour

The card fills its container up to the demo's narrow wrapper and grows in height at the
`sm` breakpoint. Icons scale accordingly; no horizontal scrolling is introduced.

## Usage

```tsx
import { DogToggleButton } from '@/components/booking/discovery/DogToggleButton';

<DogToggleButton selected={dogFriendly} onToggle={() => setDogFriendly(v => !v)} />
```
