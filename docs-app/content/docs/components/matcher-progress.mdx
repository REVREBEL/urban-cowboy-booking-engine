`MatcherProgress` shows which step of the room matcher is active. It is presentational: the
caller owns the current step. The docs demo displays all three states side by side.

<MatcherProgressStepsStoryControl />

## Props

| Prop | Values | Notes |
| --- | --- | --- |
| `step` | `1`, `2`, `3` | Highlights the active step; later steps stay muted |

## Responsive behaviour

The indicator is inline and wraps only when its container is very narrow. The comparison grid
uses one column on phones and three from `sm` up.

## Usage

```tsx
import { MatcherProgress } from '@/components/booking/discovery/RoomMatcherProgress';

<MatcherProgress step={2} />
```
