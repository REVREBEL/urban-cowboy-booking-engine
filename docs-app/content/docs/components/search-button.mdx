import { SearchButtonStoryControl, SearchButtonVariantsStoryControl } from '~/components/story-controls';

`SearchButton` accepts standard button attributes and adds a `variant` and `isLoading`
state. It renders its own magnifier SVG; do not replace it with an icon dependency.

<SearchButtonStoryControl />

## Variants

<SearchButtonVariantsStoryControl />

## Responsive behaviour

The button does not grow with its container. In the variant grid, items wrap on narrow
screens; icon-only variants keep an accessible name via `aria-label`.

## Usage

```tsx
import { SearchButton } from '@/components/booking/search/SearchButton';

<SearchButton variant="full-circle" onClick={submitSearch}>Search</SearchButton>
```
