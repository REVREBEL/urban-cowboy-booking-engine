import { PhoneInputStoryControl, PhoneInputInvalidStoryControl } from '~/components/story-controls';

`PhoneInput` parses the initial value into a country and national number, formats input as it
is typed and reports the E.164 value with a validity flag. The docs harness shows the reported
value locally; it never submits a guest form.

## Accessibility

The country selector and number field are labelled separately, and the invalid state is
exposed through `aria-invalid` so assistive technology announces the error.

## Responsive behaviour

The country flag and dial code keep a fixed width while the number field flexes, so no layout
shift occurs when switching countries on a narrow screen.

## Usage

```tsx
import { PhoneInput } from '@/components/forms/phone-input';

<PhoneInput
  value={phone}
  defaultCountry="US"
  onChange={(e164, valid) => {
    setPhone(e164);
    setValid(valid);
  }}
/>
```
