`PhotoJournal` asks about occasion, party, must-haves, quiet and budget, then ranks the rooms it
is given. The docs fixture is the deterministic studio catalogue — never live Mews inventory —
and completing the journal only updates a local status message.

## Responsive behaviour

Question cards stack on phones and form a grid at wider breakpoints. The catalogue preview
uses the same image sizing as the real journey, so a narrow viewport never clips a card.

## Usage

```tsx
import { PhotoJournal } from '@/journey/PhotoJournal';

<PhotoJournal
  adults={2}
  children={0}
  rooms={studioRooms}
  imageBaseUrl={basePath}
  galleries={{}}
  onDone={saveProfile}
  onSkip={skip}
/>
```
