`RoomPhotoTour` is the centrepiece of the photo journey: a swipeable image carousel with
per-photo amenity hotspots and an expandable detail panel. The docs demo uses a local editorial
fixture with two checked-in images; it never reads Mews inventory, price or availability, and
choosing a room only updates local text.

<RoomPhotoTourStoryControl />

## Details panel

The former `DetailsOpen` state is shown below. Hotspots open amenity details without leaving
the carousel.

<RoomPhotoTourDetailsStoryControl />

## Responsive behaviour

The tour fills its container and uses a drag-aware carousel. On narrow screens the controls
stack over the image; the detail panel becomes a scrollable sheet. The demo wrapper gives it a
full-height surface so both behaviours are visible.

## Usage

```tsx
import { RoomPhotoTour } from '@/journey/RoomPhotoTour';

<RoomPhotoTour
  room={room}
  position={0}
  count={1}
  details={false}
  onDetails={setDetails}
  onChoose={chooseRoom}
/>
```
