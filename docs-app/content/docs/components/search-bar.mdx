`SearchBar` composes the date, guest and offer selectors with the shared `SearchButton`.
The demos keep click state in a docs-only harness; they do not call the Mews API or start a booking.

<SearchBarStoryControl />

## Variants

The `variant` prop switches between circle and square action buttons.

<SearchBarSquareStoryControl />

## Loading state

<SearchBarLoadingStoryControl />

| Prop | Values | Notes |
| --- | --- | --- |
| `variant` | `circle`, `square` | Shape of the search action |
| `dateLabel` / `dateValue` | string | Date selector copy |
| `guestLabel` / `guestValue` | string | Guest selector copy |
| `promoLabel` / `promoValue` | string | Offer selector copy |
| `isLoading` | boolean | Loading presentation |
| `onSearch`, `onDateClick`, `onGuestClick`, `onPromoClick` | callbacks | Docs harness records the last action locally |

## Responsive behaviour

The selector fields wrap on narrow screens and keep accessible labels. The search action does not
shrink below its touch target.
