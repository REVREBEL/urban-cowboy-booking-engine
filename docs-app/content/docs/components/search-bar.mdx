`SearchBarExpanded` keeps property, dates, guests and promo controls in one bar and renders the
shared `SearchButton` in its `buttonSlot`. The demo uses `initialValues` and local callbacks; it
does not validate a promo code or start a booking.

<div className="docs-component-heading">

## Expanded search panel

</div>

<ExpandedSearchStoryControl />

Use the **Props** panel to set the panel shape, the `buttonVariant` of the shared `SearchButton`
in its button slot — full or icon, circle or square — and `isLoading` to preview the spinner. A
custom `buttonSlot` overrides the default action.

## Responsive behaviour

The selector fields wrap on narrow screens and keep accessible labels. The search action does not
shrink below its touch target.

The individual dropdowns are documented on the `Search dropdowns`, `DateRangePicker`,
`TravelPartyButton` and `SearchButton` pages.
