import { SearchBarStoryControl, ExpandedSearchStoryControl } from '~/components/story-controls';

`SearchBar` composes the date, guest and offer selectors with the shared `SearchButton`.
The demos keep click state in a docs-only harness; they do not call the Mews API or start a booking.
Use the **Props** panel to switch the action between circle and square and to preview the loading state.

<SearchBarStoryControl />

## Responsive behaviour

The selector fields wrap on narrow screens and keep accessible labels. The search action does not
shrink below its touch target.

## Expanded search panel

</div>

`SearchBarExpanded` is the composite variant that keeps property, dates, guests and promo controls
in one bar. The demo uses `initialValues` and local callbacks; it does not validate a promo code or
start a search.

<ExpandedSearchStoryControl />

The individual dropdowns are documented on the `Search dropdowns`, `DateRangePicker`,
`TravelPartyButton` and `SearchButton` pages.
