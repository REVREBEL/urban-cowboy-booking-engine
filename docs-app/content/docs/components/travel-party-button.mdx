import { TravelPartyStoryControl } from '~/components/story-controls';

The travel party button renders a title, subtitle and selection state. The demo uses the
component's exported `DEFAULT_TRAVEL_PARTY_OPTIONS` and a docs-only selection state.

<TravelPartyStoryControl />

The former `Default` and `Selected` stories are represented by the four-option grid; the
selected card updates immediately on click.

## Responsive behaviour

Options stack on small screens and form a two-column grid from `sm` upward. Buttons keep
their intrinsic height and wrap text rather than introducing horizontal scrolling.

## Usage

```tsx
import { FindYourStayTravelPartyButton } from '@/components/booking/discovery/FindYourStayTravelPartyButton';

<FindYourStayTravelPartyButton
  id="partner"
  title="PARTNER"
  subtitle="Just the two of us"
  isSelected={party === 'partner'}
  onSelect={setParty}
/>
```
