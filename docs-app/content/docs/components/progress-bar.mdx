import { ProgressBarStoryControl } from '~/components/story-controls';

`ProgressBar` derives complete/current/default states from a numeric `currentStep` and a step
list. It is presentational; advancing the booking is the caller's responsibility.

<ProgressBarStoryControl />

## Props

| Prop | Values | Notes |
| --- | --- | --- |
| `currentStep` | number | One-based index of the active step |
| `steps` | `{ step, label }[]` | Ordered steps to display |

## Accessibility

The current step is marked for assistive technology, and completed steps expose a check icon
in addition to colour so the state is not conveyed by colour alone.

## Responsive behaviour

Steps wrap on narrow screens instead of compressing labels; the connector line follows the
wrapped layout.

## Usage

```tsx
import { ProgressBar } from '@/components/booking/progress/ProgressBar';

<ProgressBar currentStep={2} steps={DEFAULT_BOOKING_STEPS} />
```
