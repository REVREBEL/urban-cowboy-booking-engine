`PhotoExtrasStep` presents merchandised add-ons for the selected room. It is fully controlled:
the caller owns selection, preferences and the running total. The docs harness keeps all of
that in local state and uses a single fixed-price fixture, with no Mews product lookup.

<ExtrasAvailableStoryControl />

## Former Storybook states

`Selected` and `NoExtras` are shown below; toggling an add-on updates the total immediately.

<ExtrasSelectedStoryControl />

<ExtrasEmptyStoryControl />

## Responsive behaviour

The add-on row becomes a single column on phones and expands at `sm`. The artwork fills its
card without overflow, and the action bar stays within the step wrapper.

## Usage

```tsx
import { PhotoExtrasStep } from '@/journey/PhotoExtrasStep';

<PhotoExtrasStep {...extrasState} onToggle={toggle} onNext={continueToReview} />
```
