`BookingHeader` renders the five-step progress rail and navigation callbacks. `ContactBar` is the
persistent reception action (call, email, share). The docs harness changes only local state.

## Responsive behaviour

The progress labels collapse on small screens while the step circles remain visible. The contact
action stays reachable at every width without covering the current step.
