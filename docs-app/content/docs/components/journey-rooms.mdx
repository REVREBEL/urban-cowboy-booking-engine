`PhotoRooms` presents the rooms available for a stay. With `studioCatalog` it renders the
deterministic studio catalogue; the profile can bias ordering and copy. Selecting a room in
the docs only updates a local status message — no reservation is created.

<JourneyRoomsIndexStoryControl />

## Former Storybook states

`PhotoSpreads` disables the studio index, and `WithPreferences` supplies a romance profile.

<JourneyRoomsSpreadsStoryControl />

<JourneyRoomsPreferencesStoryControl />

## Responsive behaviour

The index is a responsive grid of room cards; photo spreads become a single-column story on
phones. Controls stay reachable at every breakpoint and the wrapper introduces no horizontal
scrolling.

## Usage

```tsx
import { PhotoRooms } from '@/journey/PhotoRooms';

<PhotoRooms {...roomsState} imageBaseUrl={basePath} onChoose={chooseRoom} />
```
