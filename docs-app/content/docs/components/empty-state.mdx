import { EmptyStateStoryControl, EmptyStateWithActionStoryControl } from '~/components/story-controls';

`EmptyState` communicates that a search or list returned no results. Its illustration is a
root-relative icon, so the docs instance passes `imageBaseUrl` to resolve it under the Pages
base path. The action is a docs-only callback that updates a local status message.

<EmptyStateStoryControl />

<EmptyStateWithActionStoryControl />

## Responsive behaviour

The illustration, heading and copy are centered in a narrow reading column and wrap cleanly on
phones. No horizontal scrolling is introduced.

## Usage

```tsx
import EmptyState from '@/components/feedback/empty-state';

<EmptyState heading="Nothing available for these dates" action={{ label: 'Reset', onClick: reset }} />
```
